# Adzeniq - AI-Powered Digital Marketing Agency Website

## Overview

This is a modern, futuristic 4-page website for Adzeniq, an AI-powered digital marketing agency. The website features a neon green and black color theme with a tech-forward and conversion-focused design.

## Pages

1. **Homepage** - Showcases the agency's value proposition with a striking hero section, benefits of AI + Marketing, comparison between traditional and AI-powered marketing approaches, and client testimonials.

2. **Services Page** - Details the agency's core services: Meta Ads + AI Automation, Funnel Building, and Analytics & Performance Reporting.

3. **Blog Page** - Features a 3-column blog layout with sections for Case Studies, AI Marketing Tutorials, and Performance Marketing Insights.

4. **Contact Us Page** - Includes a contact form, quick actions for booking a demo or chatting on WhatsApp, and an FAQ section.

## Features

- Responsive design that works on all devices
- Modern, futuristic UI with neon green accents
- Smooth animations and transitions
- Interactive elements like testimonial sliders and FAQ toggles
- Blog filtering functionality
- Contact form with validation

## Customization

### Replacing Images

The website uses SVG images as placeholders. For a production site, you should replace these with actual images related to your business. The main images to replace are:

- `images/ai-robot.svg` - The hero image on the homepage
- Blog images in the `images/` directory

### Updating Content

To update the content, edit the HTML files directly. Key sections to customize:

1. **Contact Information** - Update email, phone number, and address in the footer and contact page
2. **Testimonials** - Replace placeholder testimonials with real client feedback
3. **Services Details** - Customize service descriptions to match your actual offerings
4. **Blog Posts** - Replace placeholder blog content with actual articles

### Color Theme

The color theme can be modified by editing the CSS variables at the top of the `styles.css` file:

```css
:root {
    --primary-color: #00ff8c; /* Neon green */
    --primary-dark: #00cc70;
    --primary-light: #7dffbe;
    --primary-glow: 0 0 10px rgba(0, 255, 140, 0.7);
    --secondary-color: #111111;
    --dark-color: #000000;
    --light-color: #ffffff;
    /* ... other variables ... */
}
```
